# Vydys Academy

MVP de plateforme de formation en ligne pour **vydys.com**.

## Inclus dans ce MVP
- Landing page commerciale
- Catalogue de formation
- Espace étudiant
- Classroom / cours live (interface)
- Dashboard administrateur (interface)
- Page de connexion (interface)
- Responsive mobile / desktop

## Prochaine phase backend
- Supabase Auth + PostgreSQL
- Rôles étudiant / formateur / administrateur
- Paiements (provider à choisir)
- Stockage vidéo et fichiers
- Sessions live (Google Meet / Zoom / Jitsi)
- Quiz, devoirs, notes, certificats PDF
- Emails et notifications

## Lancer localement
```bash
npm install
npm run dev
```

## Déploiement
Compatible Vercel avec Next.js App Router.
